# 标注端点几何引用：下一阶段设计

状态：设计，尚未实现。依据第六届真实失败，补充局部几何关联检查，不能把读数一致当作尺寸属于正确轮廓。

## 实际缺陷

v1.5.1默认预算新样本的内孔宽度标注挂在外轮廓附近；v1.5.2低预算首轮的内孔高度800cm虽读数正确，却用x=1000cm外墙边上的两个点表达，实际内孔右边是x=850cm。现有投影/距离检查只能核数值，不能判断标注目标是否选对。

## 拟议可选协议

为几何命令增加稳定字符串`id`，如`outer`、`opening`；为线性/对齐/半径/直径标注增加`reference`，指向同一作用域内明确的几何ID。外环/内孔属于同一HATCH时，可用明确的环编号区分。块内ID局部作用域，不偷用另一个视图或另一个块的轮廓。

先实现直线、无圆弧多段线、矩形和圆的可验证引用；有圆弧的轮廓必须明确实现边界距离后才接受，不能当直线近似通过。支持对边上的合法中点，不强迫只能标四角。检查器v4已经有对应正反例，原错误的x=1000仍必须失败。

旧计划没有引用时保持兼容。新图片计划中能定位被测轮廓的读数标注应声明引用；看不到对应几何时保留未知状态，不虚构一个几何对象来通过检查。是否将引用作为图片协议必填项，需先在保存的真实计划上测影响，并将格式修正成本单独记录。

## 验收

- 先纯逻辑检测缺ID/重ID/跨块/错轮廓/离边端点，返回命令位置和具体目标，作为已有一次自动修正的输入。
- 厘米/米归一化前后关联保持；ID不参与长度换算；历史毫米计划及保存的旧夹具不被无依据改写。
- 读数正确但端点位于错误目标边的实际失败样本必须被阻止；合法中点尺寸和原生对齐尺寸不能误判。
- 原生回执如记录引用，应区分计划预检与真实对象关系；不把元数据引用称为AutoCAD持久关联约束，不宣称用户改图后尺寸必会自动更新。
- 用同一第六届源图实际调用插件auto核对，不人工代画，不把来源检查器的放宽冒充模型进步。引用框架仍不能自动证明ID选择符合原图，需独立来源核对。
