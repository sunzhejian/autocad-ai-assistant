# 1.1.0 工作流优化与实测

验证日期：2026-11-05。本机 AutoCAD 2024，实际模型为本地已有配置 `deepseek-v4.1-flash-1017`。未改动服务地址、密钥或模型权重。

## 已交付机制

- 默认 1600px 单图增强；框选保留源图比例，精细分块可选，避免默认发送五图拖慢请求。
- 图片识别按源单位建模，后端一次性换算毫米；尺寸文字保留源图单位。兼容已有毫米坐标计划。
- 几何尺寸与声明读数一致性校验；嵌套块递归检查、总指令预算、有限坐标、变量范围、截断输出和多个计划检查。
- 最多一次计划自动修正；400/415/422 图片拒绝不再回退为无图复刻。请求预算覆盖预处理、重试和修正，取消可中断退避。
- 实际绘图通过原图形的文档命令执行，一次 U 撤销整批；切换文档时保留计划并停止自动落图；原生执行异常回滚整批。
- 推断尺寸使用橙色及“（估）”；空心填充支持内环；图框与源单位分别处理；局部图未提供字高比例时按几何范围调整标注可读性。
- 原始生成计划保留在对话上下文；新图复刻隔离旧图历史与旧图范围。
- 相同内容、提示、模型配置、协议及分块模式可复用七天内的已执行计划；可取消复用重新识别。缓存不代表原图像素识别已被人工确认。

## 速度结论与失败尝试

旧安装 DLL 对第五届同一整图为 **180.457s / 131 条指令**。新默认模式为 **181.080s / 60 条指令**，指令减少约 54%，该单样本的首次整图请求没有提速，不能据此声称总体加速。

初版五图默认分块触及 240 秒预算，因而改为用户可选。第六届初版让模型自行换算毫米时，29.407 秒后仍存在十倍尺寸冲突，被拦截且未落图；改为本地换算后该案例成功。

同图缓存的 SHA256、文件读取与完整计划校验共 25 次，查找中位数 **3.357ms**。此数不含实际落图，不等于完整复刻耗时；命中缓存时省去远程模型生成。首次复杂识图仍受所配置模型和服务速度限制。
