## 目标和验收原则

目标是让用户通过插件中配置的 AI 完成水利赛题复刻与日常绘图，减少错误、等待和返工。复刻过程必须使用插件自己的模型请求和执行器；保留模型原始回答，不以开发者代画或人工修订后的计划充当 AI 成绩。

分别报告：请求是否完整、计划是否有效、原生图元是否符合计划、是否符合源图、实际耗时。前三级通过不等于源图准确。没有独立来源核对时，回执仍标记 `source_accuracy_verified=false`。不承诺尚未验证的“完美复刻”或固定提速比例。

## 分阶段工作

按下表顺序推进，每个阶段通过验收才进入下一阶段。版本号是预定工作范围，不是已实现功能；不以日期代替测试。

| 阶段 | 工作范围 | 可交付成果与验收门槛 |
| --- | --- | --- |
| P0：可靠请求与基线 | 统一 JSON/SSE 完成判断；稳定失败分支；记录版本、请求次数和测试证据 | 截断/过滤/工具调用等异常完成均不落图、不隐藏重试；正常及省略完成标志的兼容服务仍可使用；纯回归和原生测试通过 |
| P1：赛题评测（预定 v1.5） | 固定题库样本与来源哈希；区分文字任务、矢量导入、扫描图识别；建立逐视图核对项和差距清单 | 至少三类固定赛题由插件 AI 生成原始计划；记录尺寸、轮廓、孔洞、填充、文字、耗时；同一版本重复三次，保留所有失败，不挑最好结果；人工修订单列 |
| P2：尺寸与分视图（预定 v1.6） | 视图分解、尺寸证据和约束、跨视图关联、局部重试、混合比例 | 明确读出的关键尺寸全部对应原生测量；未知值可见；错误集中反馈一次；局部重试不能重画或污染已验收视图；P1 全量对照记录有无退步 |
| P3：材料与成图质量（预定 v1.7） | 混凝土/土/砂砾等纹理、薄壁和岛屿、标注避让、中文字体与出图 | 原生 PDF 对照检验纹理、孔洞、箭头落点和关键文字；材料不能用黑色块冒充；新增凹多边形、窄壁、多孔、弧边及多比例样本，每个修复附真实缺陷用例 |
| P4：交互性能（预定 v1.8） | 鼠标/选择/缩放链路计时；缓存命中；线程和对象生命周期；大量图元执行预算 | 在同一图纸、机器、配置下做启用/停用对照，至少三轮报告中位数和 P95；记录 CAD 调用不可中断部分；新增监听必须解绑，空闲无持续轮询；不把网络延迟误算为 CAD 卡顿 |
| P5：工作流与交付 | 可恢复任务、局部修订、图纸导出、失败诊断、升级/回退及安装文档 | 新用户按文档可安装并跑完固定任务；取消、关闭图形、断网、重启后状态清楚；安装包哈希及篡改测试通过；实际 CAD 版本逐一验证后才宣称支持 |

## 每批开发流程

1. 检查工作区和本文件，只改本批范围，保留用户图纸、模型配置和附件。
2. 固定失败样本/预期，再改实现。运行相关回归；发布前跑 `tools/Test.ps1 -BuildPlugin`、原生 `tools/Test-Cad.ps1`、PDF worker 和安装包验证。
3. 新模型能力用 `ModelBenchmark.cs` 或 `test_drawing_suite.py` 通过插件 DLL 与已有配置调用；普通规则测试不能代替实际 AI 绘图。
4. 更新本文件、CHANGELOG 和验收记录，写明未通过项。原始赛题、模型密钥、用户资料、模型完整回答和 DWG 保留本地，不提交公开仓库。
5. 保存安装包、哈希及结果；运行中的旧 .NET 插件需重启 CAD 才能换版，不强行关闭用户图纸。

构建环境当前仍有 .NET Framework 4.8 Targeting Pack 缺失的 MSB3644 警告，使用已有 GAC 引用构建；须继续以实际 AutoCAD 宿主验收，不能把构建成功当作完整兼容性证明。
