# v1.2.1 交互性能优化（2026-11-05）

用户反馈鼠标移动、选择与缩放卡顿。本轮处理插件可确认的主线程开销；性能版安装后需重启 CAD，不能把逻辑基准当作实际鼠标帧率改善。

## 改动

- **后台保存**：命令统计按 2 秒窗口合并，磁盘写入与原子替换在后台执行；锁文件失败保留未保存版本，后续可重试。日志按 750ms 合并，内存快照 200 条、待写队列最多 1000 条，单条上限 8192 字符；锁文件时保留待写数据。
- **减少监听**：命令统计默认关闭，指令集提供显式开关。面板关闭时解绑文档事件；开启统计后支持重复挂接/解绑。频次刷新事件与监听生命周期事件分离；后台路径先判断可见性标记，不触碰 PaletteSet 包装器。
- **控制界面占用**：保留 40 条可见消息与 12 条完整上下文；显示文字上限 8000 字符，保留发送所需原文。聊天图片后台解码为最长边 480px 的冻结预览，最多两个解码并发，卸载控件时取消排队并释放图片。附件小预览最长边 256px。模型输入使用原图。
- **显示偏好**：标准流程与绘图完成后不再强制 `LWDISPLAY=1`，沿用用户设置。`AIPERF` / `AIPERFRESTORE` 只调整/恢复四个实时预览变量，先写备份再更改，重复启用保留最初备份。
- **测试隔离**：后台控制台无窗口启动，使用独立配置和独立数据目录；非零退出即失败，面板验证使用新建结果目录以避免沿用旧结果。

## 验证

| 项目 | 结果 |
| --- | --- |
| 纯逻辑/HTTP | **84 项通过**，包含慢磁盘不阻塞调用线程、合并更新、写入期间更新、失败恢复、锁文件重试、历史预算和监听事件分离 |
| 原生 CAD | **28 项通过**，包含几何/单位/填充/回滚/单步撤销、显示设置保留、四变量预览开关与恢复、监听挂接解绑 |
| PDF 原生 | **9 项通过**，原有导入、比例、位图依赖、恢复和撤销行为继续通过 |
| WPF | 空面板、PDF 两种模式、100 条消息追加后剩 40 条；后台预览冻结且大小 **480×339**，渲染正常 |
| PDF 进程 | 河北第 3 页依旧识别为矢量，2126 路径、234 文字；Python 路由/缓存测试通过 |
| 微基准 | 一次 10000 条统计更新约 **12–19ms**；1000 个待保存请求在受控测试中合并为 1 次后台写入，不代表 CAD 输入延迟或帧率 |

原生检查的 400 图元批次一次为 33ms，仍包括原生校核。以上测试在临时图形中执行，本轮没有控制用户当前 CAD 窗口，也没有重启它；实际鼠标流畅度还需加载新版后检查。

优化前一次 3 秒采样：CAD 约占单核 7.5%、工作集约 532MB，系统可用内存约 13GB。这只说明采样时未持续饱和，不能据此判断全部卡顿来源；本轮没有测量持续 GPU 负载。

此前会话已备份并执行减少实时预览的设置，原值为 `SELECTIONPREVIEW=3`、`COMMANDPREVIEW=1`、`HPQUICKPREVIEW=1`、`ROLLOVERTIPS=1`。原备份 `artifacts/cad-preview-before.txt` 与本地 `preview-settings.json` 保留，可用恢复命令还原。未在本轮重新操作当前窗口确认这些设置。

测试过程曾在统计开关回调引用 PaletteSet 时触发无界面宿主栈溢出。现已分离通知与生命周期，并先检查纯可见性标记；全部原生检查恢复通过。诊断用同步追踪代码已移除。

## 复现

```powershell
powershell -File tools\Test.ps1 -BuildPlugin
powershell -File tools\Test-Cad.ps1
powershell -File tools\Test-Panel.ps1
powershell -File tools\Test-Pdf-Cad.ps1 -SourcePdf '赛题.pdf' -Page 3
powershell -File tools\Test-Pdf-Process.ps1 -SourcePdf '赛题.pdf' -Page 3 -Kind vector
python -m unittest discover -s tests -p test_pdf_worker.py -v
```

本机仍存在缺少 .NET 4.8 Targeting Pack 的构建提示；已在实际 AutoCAD 2024 宿主运行 Release DLL。安装脚本校验 DLL 和 PDF 组件哈希，并将清单指向新版本文件；旧进程保留旧版本直到重启。
