# v1.3.1 配置恢复与公开发布验收

日期：2026-11-07；目标环境：Windows x64 / AutoCAD 2024 / .NET Framework 4.8。

## 功能变化

- `models.json` 改为临时文件写入、落盘后原子替换；正常更新保留上一份有效 `.bak`。配置读取失败时尝试备份，在面板显示恢复提示。重写损坏主文件前保留 `.corrupt-*`，不把损坏内容覆盖到健康备份。
- 配置条目校验列表大小、ID、模型 ID 和请求 URL；保持已有 JSON 格式及 DPAPI 加密，读写错误不打印配置内容。配置存储遵循测试数据隔离目录。
- `AIUIRESTORE` 先完整验证首次启动备份，再恢复六项变量并关闭启动整理。拒绝陌生变量、非整数和越界值；执行失败尝试回滚。`AIUI` 也先确保备份有效再改应用设置。
- 安装包提供 `Install.cmd`、安装说明、三项插件文件与完整性清单，共七个文件。安装器在写入目标前验证清单；最后原子切换加载清单并保留上一份 `.bak`。仅为 AutoCAD 2024 配置登记受信任目录，继续并存旧 DLL。
- README 增加下载入口、能力说明、测试边界和文档索引，新增贡献指南、更新记录、问题模板与 PR 模板。CI 加入有限令牌/配置文件检查、只读仓库权限和同分支旧任务取消。

## 验证边界

GitHub CI 验证纯逻辑、本地 HTTP 模拟、PDF worker 和提交文件规则；不含有许可的原生 CAD 验证。原生检查在本机隔离 CoreConsole 中执行，面板测试仅使用隔离配置和本地测试材料。本轮没有向真实模型服务发送识图任务，没有新增准确率、帧率或启动耗时承诺。

公开检查覆盖已知令牌格式、带凭据 URL、配置文件路径和 CAD/可执行二进制，不是对全部敏感信息的穷尽证明。发布 ZIP 通过固定白名单排除用户配置、题库原文件、日志、Autodesk SDK 和其他第三方二进制。
