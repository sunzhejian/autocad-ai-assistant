# v1.6.1：限制执行膨胀、保留可追溯证据

准确性优先。此批不降低来源校验、不删尺寸、不自动切换预算；减少错误计划进入CAD后造成的长时间阻塞，并补全原生回执归档。鼠标集群视频的研究结论见[并行执行取舍](swarm-research-2026-11-11.md)。

## 进入CAD之前的预算

旧400条命令上限不能限制实际工作量：一条带6002点的LINE会创建6001个独立图元；56条左右的逐层块定义/插入就可产生指数级显示工作量。新预扫描在逐环拓扑计算之前进行，并在后台预检阶段拒绝超限，尚未修改图纸。

| 资源 | 上限/估计方式 |
| --- | --- |
| 命令（含块内部） | 400，保留原限制 |
| 新建实体估计 | 5000；LINE按段计，frame保守按100个实体计 |
| 输入坐标点 | 全计划20000，包括孔边界 |
| 填充边界点 | 全计划8192；每个填充原2048限制仍保留 |
| 文字 | 合计40000字符 |
| 块定义/插入展开 | 实体估计25000；顶点、曲线/标注近似工作量及字数加权合计200000 |

块定义也检查潜在展开，计数饱和以防溢出；这是保守预算，不是AutoCAD渲染耗时预测。普通重复块和紧凑多段线继续可用。限制仅适用于结构化AI计划，不扫描或限制用户原有十万实体图纸，也不是所有填充/字体/样条性能问题的完整解决方案。

这些细小耗时差异不代表稳定提速；收益是让危险膨胀停止在纯数据预检。原始数据在本地`artifacts/budget-comparison/`。17份此前真实AI生成的最终计划继续通过新预算预检，未人为删改旧计划以通过。

246项C#回归、52项原生集成、11项原生标注格式、24项Python评测器、2项PDF worker检查通过。原生新增反例确认超预算计划不会改变实体、单位、DIMSCALE或生成回执。400普通命令的本机一次原生测试为38ms，不能推及鼠标P95或网络响应。

## 原生证据归档

`Reproduce-Cad.ps1`先复制并固定输入计划及辅助源码，再编译执行。拒绝原生报告错误、缺失回执或执行期间改变的输入；将回执与DWG/DXF一起保存在运行目录，生成schema=2清单，记录各产物SHA256、原始输入计划SHA256与回执所对应的归一化计划SHA256。

新评测器必须验证归档文件哈希、回执作用域、逐命令引用、目标句柄和实际距离。缺引用、跨作用域/空间、篡改文件、NaN距离、越界距离或错误“来源已认证”声明均拒绝。没有声明引用时记录0条、最大距离为null，避免把缺失证据当作零误差。

使用v1.6.0第二轮真实auto原始计划作未改写重放：4条引用均通过原生关系校验，最大端点距离0mm；此重放不是新AI识图试次。原始报告不被新schema覆盖，旧运行使用单独归档补充清单。临时目录以后清理也不再丢失新评测的实际回执。
